# Consumable Catalog

Extends 12_MILESTONE_TRICKS §1 (its rules stand: 6 base inventory slots, found-never-bought except Peddler R2, combat items consume the hero-act). Rarity C/U/R per 13. All penciled.

## Scrolls (rule, not a list)

Any **common or uncommon combat spell** may appear as a scroll (cast once, base face, no mana, no knowledge required). Scrolls found on barrow tiles or dropped by locks carry the + face. Rare spells never appear as scrolls — rares are places, not litter.

## Sourcing table (who drops what)

- Chests: gold / XP / 1 common-or-uncommon item.
- Barrows: + -face scrolls (Grave-weighted).
- Guardian drops: authored per guardian; tier scales with guardian power.
- Puzzle-locks: rare items and trinkets, always authored, never random.
- Peddler R2 marketplaces: 1 random scroll/week, purchasable.
- Provisioner R3: 1 random common/week.
- Seamborn encounters (future): the only source of Echo scrolls... no — rares are never scrolls; Seamborn teach Echo directly. Logged here to prevent a future contradiction.

## Counts

14 potions/combat + 10 adventure + 6 trinkets = 30 named items + the scroll rule (~30 effective scrolls). Exposure per run should be ~10–12 items; tune chest/drop tables to that, not item power.
